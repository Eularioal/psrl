## 怎样解读证据

“有界原型”指固定资源、任务数与时间预算下的受控验证。例如两个模型缓存共 3.91 GiB，3 GiB 主存池装不下两份、5 GiB 装得下，这能研究淘汰与重建，却还要检查真实 Agent 是否反复使用这些不变模型。局部请求变快、整个任务批次变快、策略训练效果提高，是三个分别测量的结果；每篇以实际完成范围陈述结论。
