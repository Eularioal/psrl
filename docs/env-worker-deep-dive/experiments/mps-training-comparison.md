## 修复状态

MPS是NVIDIA的多进程共享服务，让多个CUDA程序通过同一服务使用GPU。CUDA是NVIDIA GPU计算平台。实验关注的是两份训练同时计算时，MPS是否更高效；资源够不够、任务何时获准仍由Router管理。

[MpsControlChannel](../../../psrl/workers/env_service/mps.py#L11)按服务串行管理连接，计算作业仍可并发。原管理连接竞争导致的断连有最小复现和 32 次受管并发请求通过记录，原失败训练组也已定向完成并物理清理。见[修复证据](mps-control-fix-results.json)。这不等于服务进程崩溃、节点失联等所有故障都已验收，剩余工程范围见[工程审查](../knowledge/engineering-review.md)。

## Results：修复后配对


这是 2026-11-02 在控制通道修复后重新执行的一组配对。两组均使用提交 `96acfcc` 的独立只读源码快照，未修改执行代码或实验参数。先运行普通 CUDA 并发，确认物理释放后再运行 MPS，并为各组创建独立 Ray 实例。

两组都是两个原生 EnvWorker Docker 容器同时训练，同一张空闲 H20，每份 episode 预算 40000 MiB。负载、批大小和数据沿用[原实验配置](history/mps-training-comparison-chronology.md#2-三组对照和计时方法)的真实 autoresearch 训练，每份先预热 3 步，再计时 10 步。这次不启用 profiler，不额外占位显存，不运行 vLLM。关闭 MPS 时 Router 仍开启，也不是把两份训练强行串行，因此这仍不是历史 Router OFF/ON 对照。

| 指标 | MPS 关闭，普通 CUDA 并发 | MPS 开启 |
|---|---:|---:|
| 两份各 10 步全部完成 | 22.499 秒 | 20.160 秒 |
| 每份计时训练耗时 | 22.499 / 22.492 秒 | 20.158 / 20.159 秒 |
| 节点与容器准备 | 17.707 秒 | 19.799 秒 |
| 两份模型初始化、编译与预热 | 90.124 秒 | 92.590 秒 |
| 环境创建开始至物理清理结束 | 133.150 秒 | 136.010 秒 |
| 整卡峰值显存 | 50310.6 MiB | 50364.0 MiB |
| 作业和清理状态 | 两条均 completed、退出码 0、清理确认 | 两条均 completed、退出码 0、清理确认 |

训练段耗时减少 `1 - 20.160 / 22.499 ≈ 10.4%`，完成相同工作量的吞吐约为 **1.116 倍**，即提高约 **11.6%**。用具体数字理解：两份任务各完成 10 步，关闭 MPS 约需 22.50 秒，开启后约需 20.16 秒，总共节省约 2.34 秒，不是并发后缩短一半。

但若关心从创建环境到彻底清理的整个短流程，开启 MPS 这组反而多花约 2.86 秒，即增加约 **2.1%**。初始化和编译占用了约 90 秒，计算阶段节省的两秒多不足以抵消这次其他阶段的差异。这里的总时间不包含 shell 环境激活和 Ray 集群启动，且仅有一次配对，不能把全部差异归因于 MPS，也不能把 2.86 秒当成固定启动成本。

本次确认 MPS 组有两个真实客户端接入服务，两组全部完成，无 OOM、无控制通信错误、无清理错误。采样没有缺失，最后容器和 MPS 服务为空，GPU 无计算进程，NVML 回到约 0.19 MiB。结论明确后结束，没有为了放大收益继续增加训练步数。

**适用边界**：这说明该负载在预热后的持续训练段有约一成收益，但不足以说明短任务完整流程更快。仅有一组新配对，没有统计显著性或长期稳定性结论。本次没有重新采集内核时间线，[初次采样](history/mps-training-comparison-chronology.md#3-results)的重叠数据仍属于之前实验。它也不是原生 science/LAPS solver、完整 PSRL 强化学习训练、显存不足时的排队收益或训推同卡收益。

复现使用[原复现入口](history/mps-training-comparison-chronology.md#5-复现与跟着图读源码)的同一脚本，分别指定 `--arm 0-plain`、`--arm 0-mps`，各用新的输出目录。两组之间必须确认物理释放。紧凑结果与镜像内容 ID 见 [修复后速度结果 JSON](mps-speed-fixed-results.json)，完整日志和源码快照保存在本地 `env-service-verification/results/mps-speed-fixed-20261102/`，原始目录未纳入仓库。
