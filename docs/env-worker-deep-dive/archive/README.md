# 历史实现与阶段分析

这些文档回答“当时为什么这样设计、修复前发生了什么”。早期方案从一张卡只给一个任务，逐步发展到按显存预算放行多个任务；修复前日志和代码摘录保留了这条演进过程。

了解现在怎样运行，请先读[当前设计](../knowledge/current-design.md)；按问题选择教程可看[知识文档索引](../knowledge/README.md)。历史实验的条件和结果仍有参考价值，部署与待办以现状入口为准。
