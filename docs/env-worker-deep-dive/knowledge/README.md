当前结构与默认行为改变时，先更新[当前设计](01-架构与执行/01-Env架构_现状与完整执行流程.md)，再同步专题。机制正文解释因果和例子，实验保存固定版本数据，提案标明尚待验证的部分。同一阅读任务的必要概念、机制、算例和直接实现说明集中在主文档，用章节导航；追问优先扩充原章节。阅读用途确实独立时才拆分，迁移时同步索引、相对链接和章节入口。
