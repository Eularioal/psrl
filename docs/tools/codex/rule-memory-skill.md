# Rule、Memory、Skill：给 AI 助手的规矩、笔记和操作手册

> **核心结论**：Rule 告诉 AI 应当遵守什么，Memory 保存以后可能用得上的背景，Skill 提供完成某类任务的方法。三者让你少重复交代，也让 AI 的工作更连贯、更一致。

## 为什么需要它们

让 AI 帮忙做事时，除了“这次要做什么”，通常还得交代三类信息：团队有什么要求、之前做到哪里、这类事情通常怎么做。每次重新解释既费时间，也容易遗漏。

可以把 AI 想成刚加入团队的同事：给他一份工作规范、一份交接笔记，再给常见任务配一份操作手册。它们分别对应 Rule、Memory、Skill。这里按通用用途介绍，具体文件名和加载方式以所用产品为准。

## 三者分别做什么

| 概念 | 主要回答 | 适合保存什么 | 简单例子 |
|---|---|---|---|
| **Rule，规则** | 做事应遵守哪些要求？ | 团队约定、输出要求、操作边界 | “项目文档统一放在 `docs/`，新增文档要更新索引。” |
| **Memory，记忆** | 有哪些背景值得记住？ | 用户偏好、项目事实、历史决策、进度与经验 | “上次已完成安装，测试卡在缺少示例数据。” |
| **Skill，技能** | 这类任务应该怎样完成？ | 适用条件、执行步骤、检查方法、模板或脚本 | “整理技术文档：查资料、写解释、补例子、检查链接。” |

**Rule 的作用是减少反复纠正。** 比如每次都要求使用中文，不如把它写成长期约定。在 Codex 中，`AGENTS.md` 可以承载这类指令，工具按其发现与作用范围规则加载。[官方说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

**Memory 的作用是减少反复交接。** 它把过去工作中有用的信息保留下来，后续任务读取相关内容后，就能继续推进。记忆可能由产品自动整理，也可以是项目自行维护的笔记。保存只是第一步，还要有读取或检索机制，才能进入 AI 本次可用的信息中。Codex 的内置记忆有独立的开关和使用控制，不等于项目里的任意笔记文件都会自动生效。[官方说明](https://learn.chatgpt.com/docs/customization/memories)

**Skill 的作用是复用成熟做法。** 它通常围绕一种任务编写，例如审查代码、生成报告、处理表格。在 Codex 中，技能以 `SKILL.md` 为核心，可附带脚本、参考资料和模板。AI 先看到技能名称与简介，判断适用后再读详细步骤，也可以由用户点名使用。[官方说明](https://learn.chatgpt.com/docs/build-skills)

## 一个例子就能分清

假设你对 AI 说：“帮我写一份项目使用说明。”以下是教学示例，并非某次真实执行记录。

1. **Rule 提供要求**：“用中文写，文档放进 `docs/`，并更新索引。”它决定交付要满足哪些条件。
2. **Memory 提供背景**：“目标读者是新同事，安装步骤上次已经验证，但示例数据还没准备好。”AI 据此知道应面向谁，以及哪些信息需要补查。
3. **Skill 提供方法**：“阅读项目入口 → 核对安装命令 → 编写最小示例 → 检查链接。”AI 按这套方法组织工作。
4. **最终交付**：一份放在正确目录、适合新同事阅读的中文说明，其中明确交代示例数据的准备条件，并登记到索引。

若这次又验证了示例数据的获取方法，可将有用结论更新到记忆或项目文档中，供下次参考。是否自动保存，取决于工具功能和项目约定。

## 怎样选择放在哪里

- **希望以后都遵守的要求，写成 Rule。** 尽量短、清楚、能判断是否做到。
- **以后可能需要回忆的信息，写入 Memory。** 记录时间、适用条件和来源，过时后及时更新。
- **反复出现的一类任务，整理成 Skill。** 写清什么时候使用、需要什么输入、如何执行、最后检查什么。

同一主题可以同时涉及三者。例如，“报告必须包含数据来源”是规则，“上次报告用了哪份数据”是记忆，“如何读取数据并生成报告”是技能。

## 介绍时别混淆这些概念

**这是一种用途划分，不是三个绝对互斥的文件格式。** 记忆里也可能保存偏好，技能里也可能包含注意事项。判断重点是：这条内容主要在约束行为、保存背景，还是指导任务步骤。

**Skill 不等于给模型重新训练了一项能力。** 它主要提供可复用的指导和配套资源，实际执行仍依赖模型、工具和权限。Memory 也不等于完整聊天记录，更不保证其中的历史事实至今有效。

**Codex 的 Rules 专有功能与广义规则有区别。** 本文的 Rule 泛指工作约定，而 Codex 的 `.rules` 文件主要控制命令在沙箱外执行时是允许、询问还是禁止。普通文字要求与工具层面的权限控制要分开理解。[官方 Rules 说明](https://learn.chatgpt.com/docs/agent-configuration/rules)

**重要要求不要只寄希望于记忆。** 需要持续遵守的团队规范应明确写进规则文件或项目文档，并确认工具确实读取了它们。
