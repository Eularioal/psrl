## 阅读路径

想理解 PSRL 的进程分工、数据流和版本协调，直接读训推流程；遇到显存、合批或通信问题，再查推理机制与训练并行。PPO、GRPO 与损失推导供需要核对算法细节时选读，历史测量集中在速查专题。

## 专题文档

- [vLLM 推理机制：缓存、调度与合批](01-vLLM推理_计算瓶颈与KV缓存.md)：从 prefill/decode 的计算差异出发，解释 Roofline、同模型合批、PSRL 当前 PD 配置与 KV 传输成本，再用三分支例子展开块表、写时复制与缓存回收。
- [训练并行：模型切分与通信带宽](02-训练并行_模型切分与通信带宽.md)：按切分对象理解训练并行，再用每卡通信量和互联带宽判断并行策略应如何排布。
- [PSRL 训推协作与版本协调](03-训推协作_异步流水线与版本协调.md)：串联轨迹生成、概率重算、优势估计、参数更新与权重同步，解释 SMG、SessionRouter 与环境调度怎样配合，默认批次与分块训练何时启动、版本协调、权重分片转换和长尾等待。
- [PPO、GRPO 与 DAPO 完整原理](../02-强化学习_PPO与GRPO及DAPO.md)：同篇讲清奖励来源、PPO/GAE、组内优势、DAPO 四项机制、token 损失、熵与 KL、数值裁剪和共享参数手算。
- [性能分析：公式速查与历史实验](04-性能分析_公式速查与历史实验.md)：集中查阅符号、公式、机制对应的实验脚本与历史测量条件；历史结果不代表当前环境的重新验证。
