# GAE 的偏差-方差权衡原理

**一句话结论**：GAE 用参数 $\lambda$ 把"只信任 1 步 TD 残差"（低方差、高偏差）和"信任整条轨迹的蒙特卡洛回报"（低偏差、高方差）这两种优势函数估计方式做指数加权平均，从而在两个极端之间连续调节偏差与方差。

## 1. 问题的起点：优势函数怎么估计？

策略梯度的核心公式是：

$$
\nabla_\theta J(\theta) = \mathbb{E}\big[\nabla_\theta \log \pi(a\mid s)\cdot A(s,a)\big]
$$

关键在于 $A(s,a)$（优势函数）只能用采样数据估计，而这个估计本身就存在偏差-方差的两难：

**TD 残差（1 步估计）**

$$
\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)
$$

只用了一个真实奖励样本 $r_t$，剩下全靠 bootstrap（用 $V$ 网络去"猜"未来）。方差很小（只有一个随机变量 $r_t$），但如果 $V$ 本身有近似误差，这个误差会直接注入估计里 —— **有偏**。

**$n$ 步 / 蒙特卡洛估计**

$$
A_t^{(n)} = -V(s_t) + r_t + \gamma r_{t+1} + \cdots + \gamma^{n-1} r_{t+n-1} + \gamma^n V(s_{t+n})
$$

$n$ 越大，越接近真实回报减去 baseline，**偏差越小**（当 $n\to\infty$ 就是纯蒙特卡洛，偏差为零）。但代价是把越来越多个随机奖励项加在一起，方差随 $n$ 迅速累积 —— **方差越大**。

这就是权衡的本质：**bootstrap 用得越多 → 越依赖近似值函数 $V$ 的误差 → 偏差越大，方差越小；bootstrap 用得越少（越依赖真实采样奖励）→ 偏差越小，方差越大。**

## 2. GAE 的做法：指数加权平均所有 n 步估计

GAE 定义为对所有 $n$ 步优势估计 $A_t^{(1)}, A_t^{(2)}, A_t^{(3)}, \dots$ 做类似 TD($\lambda$) 的指数加权平均，等价的紧凑形式是：

$$
A_t^{\text{GAE}(\gamma,\lambda)} = \sum_{l=0}^{\infty} (\gamma\lambda)^l\,\delta_{t+l}
$$

也就是把未来每一步的 TD 残差按 $(\gamma\lambda)^l$ 的速度做几何衰减后累加。$\lambda$ 就是那个"旋钮"：

- **$\lambda = 0$** → $A_t = \delta_t$，退化为纯 1 步 TD 残差：方差最小，偏差最大（完全依赖 $V$ 的准确性）。
- **$\lambda = 1$** → $A_t = \sum_l \gamma^l \delta_{t+l} = R - V(s_t)$（蒙特卡洛回报减去 baseline）：偏差最小（如果奖励/转移本身无偏），方差最大。
- **$0 < \lambda < 1$** → 介于两者之间，$\lambda$ 越大越偏向蒙特卡洛（低偏差高方差），$\lambda$ 越小越偏向 TD（高偏差低方差）。

这和值函数学习里的 TD($\lambda$) / eligibility trace 是完全同构的思想，只是这里作用对象是优势函数估计，用于策略梯度。

## 3. 为什么会是这样：直觉解释

- **偏差的来源**：$V$ 是一个学出来的近似函数，不是真值。你越"相信" $V$（$\lambda$ 小），近似误差就越直接地污染优势估计；你越"不相信" $V$、越依赖真实采样的多步奖励（$\lambda$ 大），估计就越接近真实期望回报，偏差越小。
- **方差的来源**：把多个随机变量（奖励、状态转移，尤其在随机策略/随机环境下）加总，方差会累积增长。$(\gamma\lambda)^l$ 的几何衰减相当于给"远处、更不确定"的项打折，从而抑制方差增长的速度——这正是 $\lambda<1$ 时方差比纯蒙特卡洛小的原因。
- **$\gamma$ 也参与权衡**：折扣因子 $\gamma<1$ 本身也是一种偏差来源（相对无折扣的真实目标而言），但同时降低方差，因此论文里 $\gamma$ 和 $\lambda$ 是两个独立但作用类似的旋钮，实践中常见 $\gamma\approx0.99$、$\lambda\approx0.95$。

## 4. 实践含义

- $\lambda$ 越接近 1，梯度估计噪声越大，通常需要更大的 batch / 更多样本才能得到稳定的更新方向，训练可能更慢或更不稳定。
- $\lambda$ 越接近 0，训练更稳定、样本效率看起来更高，但如果 $V$ 还没学好（近似误差大），优势估计的系统性偏差会误导策略梯度方向，可能收敛到次优策略。
- 因此 $\lambda$ 的选择本质上是在"用多少个真实采样步"和"多依赖当前还不够准的值函数"之间找平衡点，这也是为什么 GAE 常和 PPO/TRPO 里对 $V$ 的持续拟合一起调参。
